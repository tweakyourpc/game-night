# Game Night v0.1.0

A multiplayer game room hosted in your own Google Sheet and bound Apps Script project, with **Wordwright, Four in a Row, Dots and Boxes, Checkers, and Fivefold**. Includes shared themes, persistent tables, invitations, optional pasted meeting links, replay JSON downloads, and conditional browser video recording.

Wordwright players can sort their rack locally, resign, or finish a stalled board through six scoreless turns with normal score adjustments. The separate Abandon match control ends a match without a winner.

**Locally verified release candidate; not production-ready.** Real Google Apps Script deployment testing is still required. Successful setup and player sign-ins alone do not complete the [Google acceptance checklist](https://github.com/tweakyourpc/game-night/blob/v0.1.0/docs/google-acceptance.md).

Download **game-night-v0.1.0.zip** from this release's Assets and follow the [browser-only installation guide](https://github.com/tweakyourpc/game-night/blob/v0.1.0/docs/install.md), then the [operator checklist](https://github.com/tweakyourpc/game-night/blob/v0.1.0/docs/operator-checklist.md). The installation needs a desktop browser and text editor to paste the supplied files into Google's editor. No public spreadsheet template is provided. The installation ZIP is separate from GitHub's automatic source-code archives.

Clasp and local development are optional; Node, Python, a terminal, and EffectCraft are not required for browser installation. Consider a separate Google account to keep the app's mail, Drive files, and service authorizations separate; this is optional and does not change player authentication.

Automatic Meet creation is not implemented. Video depends on browser APIs, codec and permissions; JSON export remains available independently. Trusted mode permits choosing another ordinary member's identity, sessions have no timed expiry, Sheets storage has limits, and custom board attribution remains unresolved. Review [known limitations](https://github.com/tweakyourpc/game-night/blob/v0.1.0/README.md#limits) and [identity/access](https://github.com/tweakyourpc/game-night/blob/v0.1.0/docs/identity.md) before regular use.
